# JSON Formatter

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-rein033-FFDD00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/rein033)

Maak JSON netjes, verklein het of controleer het op fouten, met de precieze plek van de fout. Alles in je browser.
*Format, minify and validate JSON in your browser, with the exact error location.*

**Gebruik hem:** [uselesssite.nl/json-formatter](https://uselesssite.nl/json-formatter/)

- Netjes maken met 2 of 4 spaties of tabs, of juist verkleinen tot één regel
- Fouten met regel, kolom en een pijltje naar de plek
- Sleutels alfabetisch sorteren
- Kleuren voor sleutels, tekst, getallen en true/false/null
- Statistieken: type, aantal sleutels, diepte en grootte
- Bestand openen, slepen, kopiëren en downloaden

Alles gebeurt in je browser, er gaat niets naar een server.

Onderdeel van de gratis, open-source tools op [uselesssite.nl/tools](https://uselesssite.nl/tools/).

## Ontwikkelen

Gewoon HTML, CSS en JavaScript, zonder build-stap. Open `index.html` via een willekeurige webserver.
`base.css` en `base.js` zijn gedeeld met de andere tools; de tool zelf zit in `app.js` en `style.css`.
